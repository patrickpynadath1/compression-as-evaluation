$$
r_{C,d_D}(x)=\frac{L_C(x\mid d_D)}{b(x)}.
$$

$$
r_C^{(0)}(x)=\frac{L_C(x)}{b(x)},
\qquad
s_{C,d_D}(x)=r_C^{(0)}(x)-r_{C,d_D}(x).
$$

| Symbol | Meaning |
| :--- | :--- |
| $r_{C,d_D}(x)$ | Reference-conditioned coding rate, in bits per UTF-8 byte. |
| $r_C^{(0)}(x)$ | Standalone coding rate, in bits per UTF-8 byte. |
| $s_{C,d_D}(x)$ | Reference savings, in bits per UTF-8 byte. |
